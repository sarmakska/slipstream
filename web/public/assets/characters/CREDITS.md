# Character sprites

`char_0.png` … `char_5.png` are the **MetroCity free top-down character pack**
by **JIK-A-4**, released under **Creative Commons Zero v1.0 (CC0, public
domain)**: https://jik-a-4.itch.io/metrocity-free-topdown-character-pack

CC0 waives all rights, so no attribution is legally required; this credit is a
courtesy. The pack author confirms commercial use is permitted.

Sheet layout: 16×32 px frames, 7 frames per row, rows are down / up / right
(left is the right row mirrored).

The office renderer that animates these sprites is original slipstream code.
